# laercio_mateus_andrade_oliveira_boa_rota_bus_viagens
O BoaRotaBus é uma startup criada para auxiliar empresas de turismo, transporte fretado e grupos organizados na gestão de viagens coletivas. O sistema tem como foco principal o monitoramento de passageiros em tempo real, permitindo maior controle operacional, comunicação eficiente e redução de erros durante embarques e paradas.
